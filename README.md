## What it does

`main.py` (pure Python standard library, no dependencies) writes a single
funny patch-note line announcing that human sleep has been fixed, to
`/output/entry.txt`. The line stands entirely on its own — no title, no
setup, no explanation around it.

## The line

> Fixed a bug where sleep crashed at 3 AM because the brain insisted on replaying every embarrassing thing you have ever said.

124 characters. One line. A changelog voice ("Fixed a bug where..."),
a specific and unexpected failure mode (sleep crashing at 3 AM), and a
punchline everyone recognises: the brain replaying every embarrassing
thing you have ever said.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (override with the `ENTRY_OUTPUT` environment
variable for local testing).
